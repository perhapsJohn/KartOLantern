# Kart-o'-Lantern (web build)

Monsters and cryptids racing go-karts on haunted Halloween tracks. Grand Prix,
Time Trial, VS, Lantern Battle, 1-4 players on one screen or online by race code.
Made in Godot 4.6.

This repo holds only the browser build, served by GitHub Pages at
https://perhapsjohn.github.io/KartOLantern/ (it is also a cart in the Wayside
Station arcade). Phones load `index.mobile.pck`, desktops `index.pck`.
`?room=CODE` opens the game straight into a friend's online race.

The source lives elsewhere; this is regenerated by the game's `tools/publish_web.sh`.
